Panboticon audit
================

`/panboticon-audit` skill that reports on what those sneaky bots have been up to.

Install
-------

In Claude Code:

    /plugin marketplace add rcrowley/panboticon-audit
    # or
    /plugin marketplace add ./

    /plugin install panboticon-audit@panboticon-audit

Elsewhere: IDK.

Usage
-----

    /panboticon-audit
